# Petitions

[日本語](README.md) | **English**

A RimWorld 1.7 mod that turns colonists' grievances into concrete petitions. You can accept, persuade or reject them. Harmony is not required.

## Installation

Download `Petitions-<version>.zip` from [Releases](https://github.com/pengin0503/rimworld-petition/releases), extract the `Petitions` folder into RimWorld's `Mods` folder, and enable it. GitHub's automatically generated “Source code” archive is not the mod package. If no release is available, use the `Petitions-dev` artifact from a successful [CI](https://github.com/pengin0503/rimworld-petition/actions/workflows/ci.yml) run (GitHub sign-in may be required).

## How to play

Grievances such as shared bedrooms or insufficient recreation can lead to a petition; colonists with the same grievance can join it. Use the letter or Petitions tab to promise improvements by a deadline, have a negotiator persuade the petitioners, or reject them. No response for two days counts as ignoring the petition.

Rejection, ignoring, failed persuasion and broken promises increase resentment, potentially leading to complaints, slower work, an ultimatum and departure. Slowdowns and ultimatums can be disabled; frequency and automatic responses for each grievance are configurable. Vanilla mental breaks are unchanged.

## Saves and validation

The mod can be added to an existing save, but mid-save removal is discouraged because its thoughts, hediffs and letters may remain. Back up saves before trying it. Actual in-game behavior has not been verified.

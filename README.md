# Petitions / 陳情と交渉

**日本語** | [English](README.en.md)

RimWorld 1.7向けのMODです。入植者の不満が具体的な陳情として現れ、受諾・説得・却下を選べます。Harmonyは不要です。

## 導入

[Releases](https://github.com/pengin0503/rimworld-petition/releases) から `Petitions-<版>.zip` を取得し、展開した `Petitions` フォルダをRimWorldの `Mods` に置いて有効にします。GitHubの自動生成する「Source code」はMOD本体ではありません。配布版がない場合は、成功した [CI](https://github.com/pengin0503/rimworld-petition/actions/workflows/ci.yml) の `Petitions-dev` アーティファクトを利用できます（GitHubへのログインが必要な場合があります）。

## 遊び方

相部屋、娯楽不足などによる不満が高まると陳情が届き、同じ不満を持つ入植者は連名で加わります。手紙または陳情タブから、期限までの改善を約束する、交渉役が説得する、または却下することができます。2日間回答しなければ無視扱いです。

却下、無視、説得の失敗、約束違反は恨みを増やし、不平、作業速度低下、最後通牒と退去につながります。怠業と最後通牒は無効化でき、頻度や不満別の自動応答も設定できます。バニラの精神崩壊は変更しません。

## セーブと検証状況

既存セーブに追加できますが、独自の思考・ヘディフ・手紙が残るため途中削除は非推奨です。バックアップして試してください。実際のゲーム内動作は未検証です。
